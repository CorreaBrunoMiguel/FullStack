# Formação FullStack – React & Node.js

Este repositório é o registro completo da minha jornada profissional na formação FullStack, com foco nas tecnologias **React** (front-end) e **Node.js** (back-end). Ele está sendo desenvolvido em colaboração direta com a IA da OpenAI – **ChatGPT**, em um modelo de interação estruturada e progressiva.

## 🎯 Intenção do Projeto

- Aprender de forma progressiva e sólida todos os pilares do desenvolvimento web moderno.
- Construir um **portfólio real**, com **projetos profissionais simulados** a cada módulo.
- Consolidar os conhecimentos através de teoria, quizzes, exercícios práticos e desafios.
- Manter uma organização profissional desde o início, incluindo configuração de ambiente, versionamento, e documentação clara.

---

## 🧠 Metodologia

Cada etapa de estudo segue uma estrutura padronizada:

1. **Teoria completa** – Conteúdo didático e aprofundado
2. **Quiz técnico** – Em `.md`, sem gabarito marcado
3. **Exercícios práticos** – Aplicações diretas do conteúdo estudado
4. **Desafio prático** – Simulação de tarefas de empresas reais
5. **Aprofundamento** – Quando necessário, reforço com mais teoria e exemplos
6. **Projeto de módulo** – Avaliação prática de todos os conhecimentos do módulo
