# Desafio Prático – Aula 01: Variáveis, Tipos Primitivos e Constantes

## Contexto

Você foi contratado para criar um pequeno script em JavaScript que será usado em um site para cadastro de usuários. O script deve armazenar algumas informações básicas do usuário usando variáveis e constantes.

## Requisitos

1. Crie uma variável `nomeUsuario` usando `let` e atribua seu nome completo.
2. Crie uma constante `anoNascimento` com o ano que você nasceu.
3. Declare uma variável `estaLogado` e atribua `false`.
4. Crie uma variável `saldoConta` e atribua um número decimal, representando seu saldo bancário.
5. Imprima no console todos os valores com mensagens descritivas, por exemplo:  
   `Nome do usuário: Bruno Miguel`  
   `Ano de nascimento: 1990`
6. Tente alterar o valor da constante `anoNascimento` para verificar o comportamento do JavaScript (comente essa linha para não travar o script).
7. Use `typeof` para imprimir o tipo de cada variável no console.

## Entrega

- Crie um arquivo `desafio-aula01.js` com o código solicitado.
- Comente cada passo explicando brevemente o que está fazendo.
- Execute seu script no console do navegador ou com Node.js.
- Verifique e anote os comportamentos observados, especialmente quando tentar modificar a constante.

✅ Boa sorte! Esse é um dos primeiros passos para dominar a base do JavaScript.
