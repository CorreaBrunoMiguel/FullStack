# Cenário

Você foi contratado pela empresa CorreaS (fictício). O time de desenvolvimento deseja visualizar, ainda em fase inicial, como será a simulação de um atendimento ao cliente.

## Requisitos

1. Escreva um script em JavaScript que simule o seguinte fluxo de mensagens no **console**.

   ```txt
   Iniciando atendimento
   Olá! Seja bem-vindo à Central CorreaS
   Aguardando dados do cliente...
   Pronto! Você está na filade atendimento
   ```

2. Utilize apenas o método `console.log()`

3. Inclua ao menos:

   - **Um comentário de linha única**
   - **Um comentário de múltiplas linhas** explicando o que o script faz.

4. O código deve ser executado diretamente no **console do navegador**, sem necessidade de arquivos HTML externo ou internos

:bulb: Dicas

- Para rodar seu script:
  Abra o navegador > Clique com botão direito > "Inspecionar" > "Aba "Console" > Cole e execute o código.
