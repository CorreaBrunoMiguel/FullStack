# Exercícios

---

## 1. Exibir no Console

Escreva um script que exiba no console a seguinte mensagem:

Olá, mundo! Estou aprendendo JavaScript.

---

## 2. Comentários

Copie o código abaixo e comente a segunda linha sem apagá-la:

```js
console.log('Linha 1');
console.log('Linha 2');
```

---

## 3. Ordem de Execução

Sabendo que o JavaScripit executa de forma sequencial, o que será exibido ao rodar o seguinte script?

```js
console.log('Primeiro');
console.log('Terceiro');
console.log('Segundo');
```

---

## 4. Script no Navegador

Descreva,com suas palavrar, os passos necessários para executar um código JavaScript diretamente no navegador (sem usar o VSCode).

---

## 5. Console no Navegador

Abra o console do navegador e digite a instrução abaixo:

```js
console.log('Testando o console');
```

O que aconteceu? Faça um breve comentário sobre o que viu.

---

## 6. Minha Primeira Lógica

Crie um script que representa uma sequência de ações do seu dia a dia, como:

```js
console.log('Acordar');
console.log('Tomar Café');
console.log('Estudar programação');
```
