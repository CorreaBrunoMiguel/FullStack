# Aula 01 – Introdução à lógica e ambiente JavaScript

## 1. O que é lógica de programação?

Lógica de programação é o conjunto de passos e raciocínios que permitem resolver problemas através de algoritmos e código.  
É a base para qualquer linguagem de programação, incluindo JavaScript.

---

## 2. Por que aprender lógica antes de programar?

- Ajuda a estruturar o pensamento para resolver problemas de forma clara e eficiente.
- Facilita a compreensão de conceitos como variáveis, controle de fluxo e funções.
- Melhora a capacidade de escrever código limpo e organizado.
- Torna o aprendizado de linguagens e frameworks mais simples e rápido.

---

## 3. Apresentação do JavaScript (JS)

- Linguagem de programação popular, usada principalmente para desenvolvimento web.
- Interpretada pelo navegador, mas também pode ser executada no servidor (Node.js).
- Versátil, permitindo programação procedural, funcional e orientada a objetos.
- Evolui constantemente com padrões ES6+ (ECMAScript 2015 e posteriores).

---

## 4. Configurando o ambiente de desenvolvimento

Para começar a programar em JavaScript, você pode usar:

- **Navegador Web**: Console de desenvolvimento (Chrome DevTools, Firefox DevTools).
- **Editor de Código**: VS Code (Visual Studio Code) é o mais popular.
- **Node.js**: Permite executar JavaScript fora do navegador.

### Passos básicos para configurar

1. Instale o [VS Code](https://code.visualstudio.com/).
2. Instale o [Node.js](https://nodejs.org/) (versão LTS recomendada).
3. Abra o terminal integrado do VS Code para executar comandos Node.js.
4. Use o console do navegador para testes rápidos.
