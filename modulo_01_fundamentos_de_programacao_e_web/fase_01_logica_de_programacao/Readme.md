# Fase 01 – Lógica de Programação

Nesta fase, vamos estudar os conceitos básicos de lógica utilizando **JavaScript moderno**, com foco em uma base sólida para o desenvolvimento FullStack. Os principais tópicos abordados serão:

- Variáveis e constantes (`let`, `const`)
- Tipos primitivos (string, number, boolean, null, undefined)
- Operadores básicos (aritméticos, relacionais, lógicos)
- Estruturas condicionais (`if`, `else`, `switch`)
- Laços de repetição (`for`, `while`, `do...while`)
- Funções básicas e escopo

---

## Estrutura das Aulas

Cada aula desta fase contém:

1. **Teoria detalhada**, com explicações e exemplos práticos.
2. **Quiz interativo** para fixação dos conceitos.
3. **Exercícios práticos** com respostas comentadas.
4. **Desafios reais** para aplicação dos conhecimentos.

---

## :warning: Importante

Antes de iniciar, recomendamos fortemente a leitura do [guia de execução de scripts Node.js](../executando_scripts_node.md), para garantir o correto funcionamento dos exercícios e testes no seu ambiente local.
