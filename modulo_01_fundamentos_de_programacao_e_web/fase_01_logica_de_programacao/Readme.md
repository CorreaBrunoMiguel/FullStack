# Fase 01 – Lógica de Programação

Nesta fase, vamos estudar os conceitos básicos de lógica usando JavaScript moderno, incluindo:

- Variáveis e constantes
- Tipos primitivos
- Operadores básicos
- Estruturas condicionais
- Laços de repetição
- Funções básicas

Cada aula terá teoria, quizzes, exercícios e desafios para garantir o aprendizado prático.

Vamos codar e praticar!
