# Quiz – Aula 02: Variáveis (`let`, `const`) e Tipos Primitivos

1. Qual palavra-chave permite a **reatribuição de valor** em uma variável em JavaScript?

   - [ ] const
   - [ ] static
   - [ ] var
   - [ ] let

2. O que acontece se tentarmos alterar o valor de uma constante (`const`) após sua declaração?

   - [ ] O valor é alterado normalmente
   - [ ] O JavaScript ignora a nova atribuição
   - [ ] Um erro é lançado
   - [ ] A constante se torna `undefined`

3. Qual é o tipo retornado por `typeof "Olá"`?

   - [ ] number
   - [ ] boolean
   - [ ] string
   - [ ] object

4. Qual tipo primitivo representa uma variável **sem valor atribuído**?

   - [ ] null
   - [ ] undefined
   - [ ] NaN
   - [ ] empty

5. O que o código abaixo imprimirá?

   ```js
   let nome = 'Ana';
   console.log(typeof nome);
   ```

   - [ ] "object"
   - [ ] "text"
   - [ ] "string"
   - [ ] "char"

6. O que diferencia `null` de `undefined`?

   - [ ] Ambos significam erro de sintaxe
   - [ ] `undefined` é atribuído automaticamente, `null` é atribuído manualmente
   - [ ] São sinônimos em JavaScript
   - [ ] `null` representa ausência de tipo

7. É possível declarar uma variável com `const` e não atribuir valor imediatamente?

   - [ ] Sim, o valor pode ser atribuído depois
   - [ ] Não, o valor deve ser atribuído na declaração
   - [ ] Sim, mas só se for string
   - [ ] Sim, se estiver dentro de uma função

8. Qual dos seguintes é um tipo primitivo em JavaScript?

   - [ ] array
   - [ ] function
   - [ ] string
   - [ ] object

9. Qual é o tipo retornado por `typeof true`?

   - [ ] boolean
   - [ ] string
   - [ ] number
   - [ ] undefined

10. Considerando:

    ```js
    let idade = 25;
    idade = 'vinte e cinco';
    console.log(typeof idade);
    ```

    O que será impresso?

    - [ ] number
    - [ ] string
    - [ ] undefined
    - [ ] NaN
